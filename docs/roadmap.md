# Roadmap

The first release installs and routes knowledge. These are **future directions, not shipped capabilities**:

- Add richer evidence-based selection with editable category signals and evaluation harnesses for prompts across industries.
- Expand curated resource metadata with verified license, release status and audit dates; optionally add explicitly enabled online discovery.
- Add domain-specific skill packs for commerce, dashboards and editorial experiences.
- Add package manager and framework-specific non-invasive dependency comparison.
- Run cross-platform CI and exercise live IDE agent discovery and onboarding.
- Add automated DOM accessibility and interaction QA integration without depending on screenshots.

Maintain human review for new knowledge, third-party licenses and changes to the core engine.
