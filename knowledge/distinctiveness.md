# Distinctive, not arbitrary

Generic design usually comes from default solutions applied without regard to the subject: interchangeable gradient heroes, vague slogans, stock portraits, four identical feature cards, gratuitous glass effects and motion without narrative. Distinctiveness should emerge from real content, product mechanics, audience language and constraints—not random decoration.

Run a substitution test: replace the brand and product name with a competitor's. If the page still says the same thing, the concept lacks specificity. Replace vague claims with proof: product screenshots, a short process diagram, a concrete example, meaningful data, or a quote with context and permission. Choose one recognizable device (editorial grid, illustration system, typography contrast, unusual but usable navigation) and repeat deliberately. Keep conventional patterns for critical controls.

Run an originality audit: (1) What user decision does the hero enable? (2) Which details could only belong to this product? (3) Where is the evidence? (4) Does the layout vary with content or mechanically repeat? (5) Is the identity recognizable with images disabled? (6) Does the interesting treatment survive mobile, keyboard and reduced motion? If not, revise the idea rather than adding more effects. Never imitate a reference so closely that it misleads about affiliation or licensing.
