# Design knowledge map

Use these references to drive both **high-taste creative direction** and **rigorous engineering execution**. Adapt every decision to the user's subject, category, audience, and codebase. When asked to build or redesign a UI, translate these principles directly into production code rather than outputting a theoretical essay.

| Question | Reference |
| --- | --- |
| How do we frame the concept and execute immediately? | [Strategy and design thinking](strategy.md) |
| How should typography, space and surfaces adapt by category? | [Category directions](category-directions.md) |
| How do we set art direction, visual thesis and authentic content? | [Visual direction](visual-direction.md) |
| How do we eliminate generic AI templates and build signature identity? | [Distinctiveness](distinctiveness.md) |
| How do we architect atmospheric color tokens and expressive typography? | [Color and typography](color-typography.md) |
| How do we compose varied section rhythm, bespoke components and breakpoints? | [Layout, components and responsive](layout-components-responsive.md) |
| When and how should interaction, motion, scroll or 3D be engineered? | [Interaction, motion and 3D](interaction-motion-3d.md) and [technology choices](technology-choices.md) |
| Can every user understand and operate the interface with keyboard/AT? | [UX and accessibility](ux-accessibility.md) |
| How do we hit Core Web Vitals and asset budgets? | [Performance](performance.md) |
| How do we pass the 13-Dimension Design Quality Gate and asset QA? | [Resources and QA](resources-qa.md) |
| How do we turn critique and metrics into verified improvements? | [Improvement loop](improvement-loop.md) |

Routing: For any new build or redesign, combine [strategy](strategy.md), [category directions](category-directions.md), [visual direction](visual-direction.md), and [distinctiveness](distinctiveness.md) to lock in a signature art direction, then apply [color and typography](color-typography.md) and [layout, components and responsive](layout-components-responsive.md) while coding. Audit the result against the 13-dimension gate in [resources and QA](resources-qa.md) and [UX and accessibility](ux-accessibility.md). If a project already defines a design system, honor and elevate it unless asked to reimagine it.
