# Anti-generic design

Use when a design looks interchangeable, AI-generated or stylistically fashionable without serving the product. Read [distinctiveness](../../../aether/knowledge/distinctiveness.md), [visual direction](../../../aether/knowledge/visual-direction.md) and [strategy](../../../aether/knowledge/strategy.md).

1. Run the substitution test: could the same hero and feature copy sell any competitor? Highlight generic claims and unsupported visuals.
2. Mine product-specific inputs: actual workflows, constraints, vocabulary, data, real screenshots, customer questions and proof. Flag unavailable evidence instead of inventing it.
3. Propose one coherent visual/structural device tied to those facts (e.g. a timeline of a real process, a labeled product diagram). Keep conventional controls recognizable.
4. Test the concept with images disabled, at mobile width, by keyboard and with reduced motion. Remove flourishes that reduce clarity.

Example: Replace 'Transform your workflow' above a gradient blob with a concrete before/after task diagram and a clear trial action, using verified product details. Deliver a before/after concept rationale and a list of content/asset gaps; originality is not permission to sacrifice usability or imitate someone else's trade dress.
