# Layout intelligence

Use for page architecture, section composition or a cluttered layout. Read [layout, components and responsive](../../../aether/knowledge/layout-components-responsive.md) and [strategy](../../../aether/knowledge/strategy.md).

1. List the decisions the visitor must make and order content accordingly; sketch regions before choosing columns.
2. Define a constrained spacing scale and width rules for prose vs data. Use grid for two-dimensional placement and flex for a row/column; keep logical DOM order.
3. Contrast dense evidence with breathing room without repeating the same card layout for every section. Use alignment and proximity to show relationships.
4. Test with actual copy, long labels, empty states and intermediate widths. Inspect both visual flow and screen-reader/keyboard order.

Example: For a plan comparison, keep feature labels aligned with their values and group exceptions near the relevant plan; a decorative masonry grid would slow scanning. Deliver a section map, grid/width constraints, responsive reflow notes and a list of content assumptions. Reject a layout if the primary action becomes detached from its explanation or essential text overlaps at narrow widths.
